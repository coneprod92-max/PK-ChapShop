# PK ChapShop

Marketplace locale de Parakou, Bénin.

PK ChapShop a pour objectif de réunir :
- Restaurants
- Boutiques
- Agences
- Entreprises
- Garages
- Services

## Structure

- `index.html` : page d'accueil
- `style.css` : design et responsive mobile
- `app.js` : connexion à Supabase et affichage des commerces

## Supabase

Le frontend utilise uniquement la clé **publishable** de Supabase.
Aucune clé `service_role` ne doit être placée dans ce dépôt.

## Publication

Le projet est prévu pour fonctionner sur GitHub Pages.
